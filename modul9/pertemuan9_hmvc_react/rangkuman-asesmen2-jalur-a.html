public function index() {

public function store(DaftarRequest $request) {
    $data = $request->validated();
    $data['user_id'] = auth()->id();
    $data['berkas'] = $request->file('berkas')->store('berkas','public');
    Daftar::create($data);
    return response()->json(['success' => 'Data tersimpan.']);
}

13Fitur Pencarian (Search) & Pagination

[P] Controller + index.blade.php Kegunaan: pencarian server-side memakai LIKE + paginate(10) agar data besar tetap ringan; withQueryString() mempertahankan kata kunci saat pindah halaman. Blade menampilkan link halaman dengan {{ $data->links() }}.

// Controller
$search = $request->string('search')->toString();
$data = Daftar::with('user')
    ->when($search, fn ($q) => $q->where('nama','like',"%$search%")
        ->orWhere('asal_sekolah','like',"%$search%"))
    ->latest()->paginate(10)->withQueryString();

16FormData & Respons JSON Tanpa Refresh

[P] index.blade.php (JS) Kegunaan: FormData mendukung teks + file sekaligus. processData:false dan contentType:false wajib agar jQuery tidak mengubah FormData. Update dikirim POST + _method=PUT (method spoofing). Respons JSON dipakai untuk notifikasi lalu memuat ulang tabel.

let fd = new FormData(this);
if (editing) fd.append('_method', 'PUT');

$.ajax({
    url: editing ? '/pendaftaran/' + id : '/pendaftaran',
    type: 'POST', data: fd,
    processData: false, contentType: false,
    success: function (res) { Swal.fire('Berhasil', res.success, 'success');
        loadData(); },   // tabel diperbarui tanpa reload
    error: function (xhr) { showErrors(xhr.responseJSON.errors); }
});
// Controller: return response()->json(['success' => 'Data tersimpan.']);

19Validasi Form dengan Laravel Form Request

$ php artisan module:make-request DaftarRequest Pendaftaran

[P] DaftarRequest.php Kegunaan: aturan validasi dipisah dari controller agar rapi dan dapat dipakai ulang. authorize() menentukan boleh/tidaknya request; messages() memberi pesan berbahasa Indonesia; controller cukup menulis DaftarRequest $request.

public function rules(): array {
    $daftar = $this->route('pendaftaran');
    return [
        'nama' => ['required','string','max:255'],
        'email' => ['required','email',
            Rule::unique('daftars','email')->ignore($daftar?->id)],
        'no_hp' => ['required','regex:/^[0-9+]{8,20}$/'],
        'berkas' => [$daftar ? 'nullable' : 'required', 'file',
            'mimes:jpg,jpeg,png,pdf', 'max:2048'],
    ];
}
public function authorize(): bool { return auth()->check(); }

23Dark Mode & Indikator Loading

[G] layouts/app.blade.php Kegunaan: Bootstrap 5.3 punya tema gelap bawaan lewat atribut data-bs-theme; pilihan disimpan di localStorage agar tidak hilang saat refresh. Indikator loading memberi umpan balik: spinner saat memuat, tombol nonaktif + teks “Menyimpan...” saat proses simpan.

const html = document.documentElement;
html.setAttribute('data-bs-theme', localStorage.getItem('theme') || 'light');
$('#theme-toggle').on('click', function () {
    let next = html.getAttribute('data-bs-theme') === 'dark' ? 'light' : 'dark';
    html.setAttribute('data-bs-theme', next);
    localStorage.setItem('theme', next);
});
