12CRUD Modul Utama (Pendaftaran)

public function store(DaftarRequest $request): JsonResponse {
    $data = $request->safe()->except('berkas');
    $data['berkas'] = $request->file('berkas')->store('berkas_pendaftaran','public');
    Daftar::create($data);
    return response()->json(['success' => 'Data berhasil disimpan.']);
}
public function destroy(Daftar $daftar): JsonResponse {
    $daftar->delete();
    return response()->json(['success' => 'Data berhasil dihapus.']);
}

15AJAX dengan JavaScript fetch()

Kegunaan: fetch() mengirim request di latar belakang sehingga halaman tidak reload. Header Accept: application/json membuat Laravel membalas JSON; X-XSRF-TOKEN dari cookie mencegah error 419; credentials: same-origin mengirim cookie session.

// resources/js/lib/http.ts
const res = await fetch(url, {
    method, body, credentials: 'same-origin',
    headers: { Accept: 'application/json',
        'X-Requested-With': 'XMLHttpRequest',
        'X-XSRF-TOKEN': getXsrfToken() },
});
if (!res.ok) throw new HttpError(res.status, await res.json());
return await res.json();

// dipanggil saat halaman dibuka
useEffect(() => { loadData(); }, []);

16FormData & Respons JSON Tanpa Refresh

Kegunaan: FormData mendukung teks + file sekaligus. Karena HTML form hanya mengenal GET/POST, update dikirim POST dengan _method=PUT (method spoofing). Respons JSON dipakai untuk menampilkan notifikasi lalu memuat ulang tabel via AJAX.

const formData = new FormData();
Object.entries(form).forEach(([k, v]) => formData.append(k, v));
if (file) formData.append('berkas', file);
if (editing) formData.append('_method', 'PUT');

const result = await http(editing ? urls.update(id) : urls.store,
    { method: 'POST', body: formData });
setMessage({ type: 'success', text: result.success });
await loadData();   // tabel diperbarui tanpa reload
// Controller: return response()->json(['success' => 'Data tersimpan.']);

public function rules(): array {
    $daftar = $this->route('daftar');
    return [
        'nama' => ['required','string','max:255'],
        'email' => ['required','email',
            Rule::unique('daftars','email')->ignore($daftar?->id)],
        'no_hp' => ['required','regex:/^[0-9+]{8,20}$/'],
        'berkas' => [$daftar ? 'nullable' : 'required', 'file',
            'mimes:jpg,jpeg,png,pdf', 'max:2048'],
    ];
}
